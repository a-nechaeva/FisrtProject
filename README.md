_Научиться работать с сетью. Интегрировать библиотеку retrofit в свое приложение._

Реализовать запрос каталога приложений:
* Используя библиотеку retrofit, реализовать get запрос за данными каталога приложений.
* В качестве ссылки следует использовать http://185.103.109.134/catalog.
* Интегрировать запрос в свое приложение, чтобы данные приходили с сервера и отображались.
* Если требуется, то добавить мапперы данных.
Реализовать запрос информации о приложении:
* Используя библиотеку retrofit, реализовать get запрос за данными для конкретного приложения в отдельности по его id.
* В качестве ссылки следует использовать http://185.103.109.134/catalog/{id} , где id – это айдишник, который в сущностях catalog. Этот эндпоинт нужен для получения более подробной информации, в дальнейшем он вам понадобится. На данный момент его интегрировать никуда не надо.
* Если требуется, то добавить мапперы данных.
